## 🏗️ ForgeAI Studio

پلتفرمِ کاملِ هوش مصنوعیِ لوکال برایِ ویندوز:

```
FORGEAI STUDIO
├── 💬 Chat        — استریم با مدل‌های لوکال + زنجیرهٔ آنلاینِ اختیاری + لایهٔ کیفیت فارسی
├── ✏️ Edit        — ویرایشِ کد با تأییدِ خط‌به‌خط
├── ⌨ Terminal    — اجرای دستور + تاریخچه
├── 🧩 Plugins    — سیستمِ کاملِ افزونه
├── 🛡️ Guardian   — گاردِ قانون‌مندِ داخلی
├── 🔐 License     — فعال‌سازی خودکار · بازبینی زنده · ورود دومرحله‌ای TOTP
├── 🔌 API Hub    — endpoint شخصی :7800/v1
└── 🌐 Multi-LLM  — ۳۲۳ مدل در یک زنجیره
```
